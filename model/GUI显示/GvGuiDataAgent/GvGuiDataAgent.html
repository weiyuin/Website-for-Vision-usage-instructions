GvGuiDataAgent

Chức năng

GvGuiDataAgent là đối tượng toàn cục của lớp GcScriptGuiDataAgent, dùng để hiển thị mảng đối tượng GUI (text, line, rect, circle, annulus, profile, v.v.) lên cửa sổ hình ảnh (View). Tuyệt đối không được tự tạo mới một đối tượng GcScriptGuiDataAgent.

Giao diện (Interface)

Phân loại Tên giao diện Mô tả
Hàm thành viên SetGraphicDisplay(str, value) Hiển thị mảng đối tượng GUI lên cửa sổ hình ảnh đã chỉ định.

Chi tiết chức năng

SetGraphicDisplay(str, value)

  • Chức năng: Đẩy toàn bộ mảng đối tượng GUI lên cửa sổ hình ảnh để hiển thị (thường gọi mỗi frame hoặc khi cần cập nhật overlay).

  • Tham số:

    • str: Tên cửa sổ hình ảnh (View), ví dụ "View-1", "View-2", "MainView"…

    • value: Mảng các đối tượng GUI cần hiển thị, kiểu GcScriptGuiArray.

  • Giá trị trả về: bool – True nếu hiển thị thành công.

Lưu ý quan trọng

  1. Tuyệt đối không tự tạo đối tượng GcScriptGuiDataAgent. Hệ thống đã cung cấp sẵn đối tượng toàn cục GvGuiDataAgent để sử dụng trực tiếp.

Ví dụ code

1、Thêm và hiển thị GUI (ví dụ vẽ chữ “text” tại vị trí (0,0) trên View-1)

python guiArray = GvVisionAssembly.GcScriptGuiArray() guiText = GvVisionAssembly.GsScriptGuiText() guiText.sScriptGuiStyle = guiStyle # guiStyle là biến GsScriptGuiStyle đã định nghĩa trước guiText.strText = "text" # nội dung chữ cần hiển thị guiText.posX = 0.0 # tọa độ X guiText.posY = 0.0 # tọa độ Y guiText.deg = 0.0 # góc xoay (độ) guiArray.Add(guiText) # thêm vào mảng GvGuiDataAgent.SetGraphicDisplay("View-1", guiArray) # hiển thị lên View-1
