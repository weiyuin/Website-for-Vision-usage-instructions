GsScriptGuiAnnulus

Chức năng

Đối tượng GUI dùng để hiển thị vùng vòng tròn đồng tâm (annulus) lên cửa sổ hình ảnh (View).

Giao diện (Interface)

Phân loại Tên thuộc tính Mô tả
Thuộc tính sScriptGuiStyle Phong cách hiển thị (kiểu GsScriptGuiStyle), bao gồm độ dày nét, màu sắc, v.v.
annulus Vùng annulus cần hiển thị (kiểu scAnnulus).

Chi tiết chức năng

sScriptGuiStyle

  • Chức năng：Phong cách hiển thị GUI, kiểu GsScriptGuiStyle.

annulus

  • Chức năng：Vùng vòng tròn đồng tâm cần hiển thị lên View, kiểu scAnnulus.

Lưu ý

Không có.

Ví dụ code

```python # Gui风格 guistyle = GvVisionAssembly.GsScriptGuiStyle() guistyle.nLineWidth = 2 # độ dày nét vẽ guistyle.clrLineColor = [0, 255, 0] # màu xanh lá (RGB) # 圆环Gui对象 pos = GvVisionAssembly.sc2Vector(100, 100) # tâm tại (100, 100) annulus = GvVisionAssembly.scAnnulus(pos, 20, 3) # bán kính chuẩn 20, radial scale 3 annulus_gui = GvVisionAssembly.GsScriptGuiAnnulus() annulus_gui.sScriptGuiStyle = guistyle annulus_gui.annulus = annulus # Gui数组 guiarray = GvVisionAssembly.GcScriptGuiArray() guiarray.Add(annulus_gui) # thêm đối tượng GUI vào mảng # 将Gui数组设置到视图 GvGuiDataAgent.SetGraphicDisplay("View-1", guiarray) ```
