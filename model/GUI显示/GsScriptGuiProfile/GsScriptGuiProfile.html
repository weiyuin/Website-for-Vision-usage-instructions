GsScriptGuiProfile

Chức năng

Đối tượng GUI dùng để hiển thị hình ảnh profile (đồ thị cường độ biên/đồ thị quét đường thẳng) lên cửa sổ hình ảnh (View).

Giao diện (Interface)

Phân loại Tên thuộc tính Mô tả
Thuộc tính sScriptGuiStyle Phong cách hiển thị (kiểu GsScriptGuiStyle), bao gồm độ dày nét, màu sắc, v.v.
profile Hình ảnh profile cần hiển thị (kiểu GsProfileData).

Chi tiết chức năng

sScriptGuiStyle

  • Chức năng: Phong cách hiển thị GUI, kiểu GsScriptGuiStyle.

profile

  • Chức năng: Dữ liệu profile cần hiển thị lên View, kiểu GsProfileData.

Lưu ý

  1. Khi dùng script để đặt profile thì có thể không cần thiết lập phong cách hiển thị.

  2. Nếu trong một công cụ script thêm nhiều đối tượng profile GUI thì chỉ hiển thị profile đầu tiên.

  3. Nếu đã quyết định dùng script để thêm profile vào View thì không được thêm thủ công (manual) profile vào cùng View đó. Ngược lại cũng vậy.

Ví dụ code

```python # Gui数组 guiArray = GvVisionAssembly.GcScriptGuiArray() # Gui轮廓 guiProfile = GvVisionAssembly.GsScriptGuiProfile() guiProfile.profile = GvTool.GetToolData("Thư mục ảnh_003.Đầu ra profile ảnh") # lấy profile từ công cụ khác # 将轮廓Gui添加到Gui数组 guiArray.Add(guiProfile) # 将Gui数组添加的View显示 GvGuiDataAgent.SetGraphicDisplay("View-1", guiArray) ```
