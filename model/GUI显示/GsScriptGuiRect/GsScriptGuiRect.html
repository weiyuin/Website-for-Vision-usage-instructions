GsScriptGuiRect

Chức năng

Đối tượng GUI dùng để hiển thị hình chữ nhật (rectangle) lên cửa sổ hình ảnh (View).

Giao diện (Interface)

Phân loại Tên thuộc tính Mô tả
Thuộc tính sScriptGuiStyle Phong cách hiển thị (kiểu GsScriptGuiStyle), bao gồm kiểu nét, độ dày, màu sắc, nhãn, font chữ, v.v.
rect Hình chữ nhật cần hiển thị (kiểu scRect).

Chi tiết chức năng

sScriptGuiStyle

  • Chức năng: Phong cách hiển thị GUI, kiểu GsScriptGuiStyle.

rect

  • Chức năng: Vùng hình chữ nhật cần hiển thị lên View, kiểu scRect.

Lưu ý

Không có.

Ví dụ code

```python # 设置GUI格式 guiStyle = GvVisionAssembly.GsScriptGuiStyle() guiStyle.bVisible = False # không hiển thị vùng fill (nếu có) guiStyle.nLineStyle = 3 # kiểu nét (3 thường là nét đứt) guiStyle.nLineWidth = 2 # độ dày nét 2 pixel guiStyle.clrLineColor = [255, 0, 0] # màu đỏ (RGB) guiStyle.bLabelVisible = True # hiển thị nhãn guiStyle.strLabelFont = "宋体" # font SimSun (宋体) guiStyle.lFontSize = 10 # cỡ chữ 10 ########## GUI设置 ################ # 获取GUI显示数组 guiArray = GvVisionAssembly.GcScriptGuiArray() # 矩形GUI guiRect = GvVisionAssembly.GsScriptGuiRect() rect0 = GvVisionAssembly.scRect(GvVisionAssembly.sc2Vector(100,100), GvVisionAssembly.sc2Vector(200,300)) # góc trái trên (100,100), góc phải dưới (200,300) guiRect.rect = rect0 guiStyle.strLabel = "矩形" # nội dung nhãn guiRect.sScriptGuiStyle = guiStyle guiArray.Add(guiRect) # 将GUI数组设置到视图 GvGuiDataAgent.SetGraphicDisplay("View-1", guiArray) ```
