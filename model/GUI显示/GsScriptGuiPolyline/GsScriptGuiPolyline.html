GsScriptGuiPolyline

Chức năng

Đối tượng GUI dùng để hiển thị đa giác (polygon/polyline) lên cửa sổ hình ảnh (View). Thường được dùng trong công cụ Blob để vẽ contour hoặc ROI đa giác.

Giao diện (Interface)

Phân loại Tên thuộc tính Mô tả
Thuộc tính sScriptGuiStyle Phong cách hiển thị (kiểu GsScriptGuiStyle), bao gồm kiểu nét, độ dày, màu sắc, nhãn, font chữ, v.v.
polyline Đa giác cần hiển thị (kiểu scPolyline).

Chi tiết chức năng

sScriptGuiStyle

  • Chức năng: Phong cách hiển thị GUI, kiểu GsScriptGuiStyle.

polyline

  • Chức năng: Đa giác/polyline cần hiển thị lên View, kiểu scPolyline.

Lưu ý

Không có.

Ví dụ code

```python # 设置GUI格式 guiStyle = GvVisionAssembly.GsScriptGuiStyle() guiStyle.bVisible = False # không fill vùng bên trong guiStyle.nLineStyle = 3 # kiểu nét (3 thường là nét đứt) guiStyle.nLineWidth = 2 # độ dày nét 2 pixel guiStyle.clrLineColor = [255,0,0] # màu đỏ (RGB) guiStyle.bLabelVisible = True # hiển thị nhãn guiStyle.strLabelFont = "宋体" # font SimSun (宋体) guiStyle.lFontSize = 10 # cỡ chữ 10 ### GUI设置 # 获取GUI显示数组 guiArray = GvVisionAssembly.GcScriptGuiArray() # 多边形GUI guiPolyline = GvVisionAssembly.GsScriptGuiPolyline() p0 = GvVisionAssembly.sc2Vector(149,233) p1 = GvVisionAssembly.sc2Vector(103,178) p2 = GvVisionAssembly.sc2Vector(100,99) p3 = GvVisionAssembly.sc2Vector(200,99) p4 = GvVisionAssembly.sc2Vector(200,200) # 添加构成多边形的点 VectorVec = GvVisionAssembly.sc2VectorVec() VectorVec.append(p0) VectorVec.append(p1) VectorVec.append(p2) VectorVec.append(p3) VectorVec.append(p4) polyline0 = GvVisionAssembly.scPolyline(VectorVec, True) # True = đóng kín guiPolyline.polyline = polyline0 guiStyle.strLabel = "多边形" # nội dung nhãn (có thể xóa dòng này nếu không muốn hiển thị label) guiPolyline.sScriptGuiStyle = guiStyle # 向GUI显示数组添加GUI guiArray.Add(guiPolyline) # 将GUI数组设置到视图 GvGuiDataAgent.SetGraphicDisplay("View-1", guiArray) ```
