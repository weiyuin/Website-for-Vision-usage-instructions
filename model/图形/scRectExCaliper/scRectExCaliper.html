scRectExCaliper

Tính năng

Biểu diễn thước kẹp hình chữ nhật biến dạng (Variable Rectangular Caliper), điều khiển đồ họa Gui tương ứng là scGuiRectEx, đại diện cho tập hợp các Caliper bên trong hình chữ nhật biến dạng, hình chữ nhật ngoài cùng là Variable Rectangle, và các hình chữ nhật nhỏ bên trong là các Caliper.

Hình 1 Sơ đồ minh họa Variable Rectangular Caliper

Interface

Phân loại Tên Interface Mô tả Interface
Constructor scRectExCaliper scRectExCaliper() Hàm khởi tạo mặc định.
Hàm GetCaliperNum Lấy số lượng Caliper.
GetCalipers Lấy tất cả các Caliper
Thuộc tính rectEx Hình chữ nhật biến dạng nơi tọa lạc các Variable Rectangular Caliper
caliperWidth Chiều rộng Caliper
caliperSpace Khoảng cách (Spacing) giữa các Caliper

Mô tả chi tiết

scRectExCaliper()

  • Tính năng: Khởi tạo đối tượng scRectExCaliper.

  • Tham số: Không.

  • Giá trị trả về: Không.

GetCapliperNum()

  • Tính năng: Lấy số lượng Caliper.

  • Tham số: Không.

  • Giá trị trả về: Số lượng Caliper, kiểu nguyên (Integer).

GetCaplipers()

  • Tính năng: Lấy tất cả các Caliper trong Variable Rectangular Caliper.

  • Tham số: Không.

  • Giá trị trả về: Tất cả các Caliper trong Variable Rectangular Caliper, dưới dạng Vector thuộc kiểu scRectEx, tương đương với List trong Python.

rectEx

  • Tính năng: Biểu diễn hình chữ nhật biến dạng nơi đặt Caliper, kiểu scRectEx, có quyền đọc/ghi (R/W).

caliperWidth

  • Tính năng: Biểu diễn chiều rộng Caliper, kiểu nguyên, có quyền đọc/ghi (R/W).

caliperSpace

  • Tính năng: Biểu diễn khoảng cách giữa các Caliper, kiểu nguyên, có quyền đọc/ghi (R/W).
