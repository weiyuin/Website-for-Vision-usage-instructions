Hướng dẫn sử dụng Ghi log bất đồng bộ (Async Logging)

Giải thích

  • Module ghi log này được đóng gói dựa trên thư viện bên thứ ba loguru của Python
  • Hỗ trợ ghi log bất đồng bộ (dùng hàng đợi - queue)
  • Log được in theo định dạng: “năm-tháng-ngày giờ:phút:giây:mili giây - nội dung log”
  • Mỗi ngày sẽ tự động tạo một file log mới
  • Vào 00:00 hàng ngày, file log của ngày hôm trước sẽ được tự động sao lưu, tên file backup có dạng: “tên_file.thời_gian_của_dòng_log_đầu_tiên.txt”
  • Log sẽ được lưu tối đa 1 tháng, các file quá 1 tháng sẽ tự động bị xóa

Các bước sử dụng và ví dụ

  • Bước 1: Import GvLog

  • Bước 2: Ghi log

    Ví dụ mã:

    from GvAsyncLog import GvLog

    GvLog.Log("D:/标定.txt", "Helelo")

    Lưu ý:

    File log sẽ tự động tạo mới mỗi ngày, bạn không cần thay đổi tên file trong script theo từng ngày.
