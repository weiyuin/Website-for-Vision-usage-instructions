GvVar

Chức năng

GvVar là đối tượng toàn cục của lớp GcVisionAssemblyVar dùng để đọc/ghi các biến trong Quản lý biến (Variable Manager). Tuyệt đối không được tự tạo mới một đối tượng GcVisionAssemblyVar — hệ thống đã cung cấp sẵn đối tượng GvVar để sử dụng trực tiếp.

Giao diện (Interface)

Phân loại Tên giao diện Mô tả
Hàm thành viên GetVar(str, is_raw_string=False) Lấy giá trị biến (trả về bản sao).
SetVar(str, value, is_raw_string=False) Đặt giá trị cho biến.

Chi tiết chức năng

GvVar.GetVar(str, is_raw_string=False)

  • Chức năng: Lấy giá trị của biến trong Quản lý biến. Giá trị trả về là bản sao (copy), nên sửa đổi biến này sẽ không tự động cập nhật vào Variable Manager.

    python num = GvVar.GetVar("#L1") # lúc này #L1 = 1 num = 5 # #L1 trong Variable Manager vẫn là 1

    Nếu muốn thay đổi thực sự → phải dùng thêm GvVar.SetVar().

  • Tham số:

    • str: Tên biến, ví dụ "#L1", "#L2", "@G1", "@G2", "#S10", v.v.

    • is_raw_string: bool, mặc định False (hầu như không cần dùng).
      • False → chuỗi được chuyển sang UTF-8.
      • True → trả về dữ liệu bytes gốc (dùng khi biến chứa dữ liệu nhị phân có byte 0x00, ví dụ dữ liệu giao tiếp, barcode, QR…).

      Ví dụ: biến #S0 chứa chuỗi hex 05 4C 4D 11 00 51 → nếu is_raw_string=False sẽ bị cắt tại 00 → chỉ còn “05 4C 4D 11”. Dùng True sẽ lấy đủ 6 byte.

  • Giá trị trả về: Bản sao của giá trị biến (int, float, str, list, bytes…).

GvVar.SetVar(str, value, is_raw_string=False)

  • Chức năng: Ghi/đặt lại giá trị biến trong Variable Manager.

    python num = GvVar.GetVar("#L1") # num = 1 num = 5 GvVar.SetVar("#L1", num) # lúc này #L1 trong Variable Manager đã thành 5

  • Tham số:

    • str: Tên biến (ví dụ "#L1", "@G1").
    • value: Giá trị mới cần đặt.
    • is_raw_string: bool, mặc định False.
      • False → chuỗi được chuyển sang GBK trước khi ghi.
      • True → ghi trực tiếp bytes gốc (dùng khi cần ghi dữ liệu nhị phân).

    Ví dụ: GvVar.SetVar("#L0", b'\xAA', True) → biến #L0 sẽ nhận đúng byte AA.
    Nếu để False thì sẽ bị chuyển thành “?” (0x3F).

  • Giá trị trả về: bool – True nếu đặt thành công.

Lưu ý quan trọng

1. Tuyệt đối không tự tạo đối tượng GcVisionAssemblyVar. Hãy dùng luôn đối tượng toàn cục GvVar có sẵn.

2. GetVar() chỉ trả về bản sao → muốn thay đổi thực sự trong Variable Manager thì phải gọi SetVar().
